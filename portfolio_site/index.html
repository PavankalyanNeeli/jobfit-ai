The Product Suite

App 1: Shortlist Predictor

Built for the modern tech recruiter. Upload a candidate's PDF resume and a Job Description. Our ML pipeline scores the candidate from 0-100% and uses SHAP Waterfall charts to transparently show exactly which skills influenced the decision.

Streamlit pdfplumber SQLite

App 2: Skill-Gap Coach

Built for the candidate. Upload your resume and select a target role (e.g. Data Scientist). The recommender engine uses ablation testing to simulate adding missing skills to your resume, ranking the Top 5 skills you must learn to boost your hiring probability.

The Data Engine

A highly modular data backbone. Features a custom Knowledge Graph that resolves unstructured text into normalized technical categories. Operates on a seamless synthetic data generator, primed for a drop-in replacement with Kaggle HR Analytics data in production.
